# 🚴 Cyclistic Bike Share Analysis

Google Data Analytics Professional Certificate Capstone Project

---

## 📌 Project Overview

This project was completed as the capstone project for the Google Data Analytics Professional Certificate.

The objective was to analyze Cyclistic bike-share data to understand how casual riders and annual members use the service differently and provide business recommendations to increase annual memberships.

The project follows the complete data analytics process:
Ask → Prepare → Process → Analyze → Share → Act.

## 🎯 Business Problem

Cyclistic is a bike-sharing company that wants to convert more casual riders into annual members.

The marketing team needs data-driven insights about the differences between casual riders and members to design effective marketing campaigns.

## 📊 Dataset

- Source: Divvy Bike Share Data
- Type: Public Dataset
- Time Period: [2025/07-2026/06]
- Format: CSV

The original raw dataset is publicly available. Due to its large size, it is not included in this repository.

## 🔄 Data Cleaning

The following preprocessing steps were performed:

- Removed duplicate records
- Checked for missing values
- Converted data types
- Standardized column names
- Calculated ride duration
- Extracted weekday and month information
- Removed invalid ride durations

## 📈 Data Analysis

The analysis focused on:

- Average ride duration
- Bike type preferences
- Ride frequency by weekday
- Seasonal trends
- Member vs casual rider behavior

## 💡 Key Insights

- Casual riders take longer rides than members.
- Members ride more frequently during weekdays.
- Casual riders are more active on weekends.
- Electric bikes are popular among casual riders.
- Ride activity increases during summer.

## ✅ Recommendations

- Introduce weekend membership offers.
- Promote annual memberships during peak seasons.
- Target casual riders with personalized marketing campaigns.
- Encourage electric bike usage through member-exclusive benefits.
